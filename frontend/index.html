Simulator Help

Getting started

  1. Choose Quick Mode for the simplest workflow or Research Mode for all analyses.
  2. Set the configuration or load a preset.
  3. Click Run Simulation.
  4. Use the analysis tabs to inspect only the result you need.

Modes

Quick Mode keeps the core workflow visible. Research Mode exposes target, technology-gap, pipeline and scaling analyses.

Benchmark

The Benchmark tab reproduces the published SSD-class optimized configuration. Change its parameters to test your own architecture against the reference.

Useful tip

Hover over technical labels and controls for short explanations. Your mode and onboarding preference are remembered on this browser.
